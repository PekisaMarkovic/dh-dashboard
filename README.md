# DH Dashboard

React + TypeScript + Vite + Tailwind. Talks to `dh-api`.

- Runs on **http://localhost:4300** (`pnpm dev`)
- Setup: `cp .env.example .env`, check `VITE_API_URL`, then `pnpm install && pnpm dev`
- Language: English and Serbian, every user keeps their own choice (top menu or profile)
- Build: `pnpm build`
